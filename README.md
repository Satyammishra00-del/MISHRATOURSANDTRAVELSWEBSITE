> **"Your Journey, Our Responsibility"**  
> Premier travel solutions, group packages, pilgrimage yatras, corporate travel & luxury transportation based in Boisar, Maharashtra.

## 🌟 Highlights & Features

- **Full-Page Scroll-Driven Cinematic Animation**: Continuous frame-by-frame canvas rendering synchronized smoothly across 0% to 100% of the entire page scroll.
- **Interactive Tour Booking Engine**: Direct routing of customer inquiries and package customization to Shivam Mishra (`8767213391`) & Satyam Mishra (`9922355049`) via WhatsApp.
- **Dynamic Destination Category Filter**: Real-time filtering across Mountains & Hills, Beaches, Spiritual Yatras, and Royal Heritage circuits.
- **Animated Milestones Counter**: Micro-animated counters highlighting 10+ years of excellence, 1,200+ tours, and 15,000+ satisfied passengers.
- **Interactive Testimonial Carousel**: Multi-card responsive slider showcasing authentic reviews.
- **Mobile-First Responsive Layout**: Tailwind utility architecture with custom glassmorphic styling, gold accent themes, and optimized touch ergonomics.

## 📁 Repository Structure

```
├── index.html          # Main semantic HTML5 single-page application
├── styles.css          # Custom styling, gold gradient utilities, and canvas overlay rules
├── script.js           # Full-page scroll canvas engine, booking generator, and sliders
├── frames/             # 240 high-definition sequence frames for scroll-driven animation
└── README.md           # Documentation
```

## 🚀 Running Locally

You can run this project locally using Python's built-in HTTP server or any static file server:

```bash
# Start local server
python -m http.server 8000
```

Open your browser and navigate to:
```
http://localhost:8000/index.html
```
